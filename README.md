## What I Work On

- **ML evaluation and robustness** — identifying hidden model failure, shortcut reliance, and unreliable performance signals  
- **Geospatial AI** — remote sensing, segmentation, and input-efficiency for landslide detection  
- **Visual attention modelling** — analysing where saliency models diverge from human behaviour  
- **Explainability and auditability** — feature selection, attribution, and evidence for trustworthy model use
